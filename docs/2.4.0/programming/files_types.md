Fiskheroes uses several file types for heropacks, different file types can have vastly different syntax and uses.

## JS

JS or JavaScript is probably the most common language you will be using in fiskheroes. JS files are used for data and renderer files. You can find more about the language at [W3Schools JS](https://www.w3schools.com/js/).

### JSON

JSON is a lightweight, easy to understand format. It's used to simplify information to either read or write data. In fiskheroes its used for many things like powers, beams, nodes, your heropack.json file and more. You can find more about the format with [W3Schools JSON](https://www.w3schools.com/js/js_json.asp).

### FSK

FSK is a language built specifically for fiskheroes animations, it's math based and supports comments by using the `;` symbol before text. You can find more about the language with `tutorial to be added`. You can make Visual Studio Code support the language with the [FSK Plugin](https://marketplace.visualstudio.com/items?itemName=FiskFille.fsk).

### Other file types

* PNG: Image format that supports lossless data compression; used for textures.
* Ogg: Multimedia format created for efficient storing and streaming; used for sounds.
* Tbl: Low space model format created for the [Tabula mod](https://www.curseforge.com/minecraft/mc-mods/tabula-minecraft-modeler); used for models.
* MCMeta: Animation configuration file created for Minecraft to animate a PNG file of the same name; used for animating item textures.
